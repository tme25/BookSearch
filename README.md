Это простая программа, что выполняет поиск книг через OpenLibrary API.
Для получения необходимого результата нужно выбрать способ поиска (1 и 2 - по названию и автору соответственно), затем ввести название, в результате чего программа выведет названия книг, их авторов и даты выпусков в скобках.
Ветка: feature/author-search
