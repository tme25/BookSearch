Это простая программа, что выполняет поиск книг через OpenLibrary API.
Для получения необходимого результата нужно выбрать способ поиска (1 или 2 - по названию или автору соответственно), затем ввести название, в результате чего программа выведет названия книг, их авторов и даты выпусков в скобках.
Ветка: feature/author-search
